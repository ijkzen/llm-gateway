# 02: 备份导入放开跨虚拟模型共享

**What to build:** 从网关导出的备份（含同一供应商模型出现在多个虚拟模型）可以在导入时通过校验，不再报「同一次导入内同一供应商模型不可重复」；同一虚拟模型内重复成员仍被拒绝。

**Blocked by:** 01 后端解除互斥映射（迁移 + 管理 API）

**Status:** ready-for-agent

- [ ] 备份导入不再拒绝跨虚拟模型共享成员
- [ ] 同一虚拟模型内重复成员仍报错（去重语义保留）
- [ ] 自然键唯一（供应商名/display_id/api key name）校验不变
- [ ] 单元测试：跨虚拟模型共享的备份 JSON 校验通过；组内重复仍失败
- [ ] 备份相关文档表述（自然键唯一/成员重复）与新规则一致
