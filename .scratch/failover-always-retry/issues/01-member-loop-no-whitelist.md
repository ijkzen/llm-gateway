# 01: 成员尝试循环去状态码白名单，任何失败都降级

**What to build:** 虚拟模型成员尝试循环中「是否降级」的判定不再依赖 HTTP 状态码白名单（408/429/500/502/503/529）——只要对某成员的转发失败（本地失败或上游 >=400），在降级策略开启且还有后继成员时一律尝试下一成员。死抽象（失败分类枚举、状态码白名单谓词、判定方法）连同其 3 个失效单测一并删除；HTTP 失败降级日志去掉「可重试」措辞。chat 与原生透传共用循环，自动统一生效；fallback_strategy=0、熔断计数、-N 后缀落库行均不变。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 4 处失败分支（解密/构造/调用/上游 >=400）降级判定统一为「降级策略开启 && 还有后继成员」，不再查询状态码
- [ ] 删除失败分类枚举、状态码白名单函数与判定方法（死抽象）及其 3 个单元测试；无残留编译警告
- [ ] HTTP 失败降级日志文案不含「可重试」字样
- [ ] 既有测试全绿：429 降级、全成员失败、fallback=0 直接失败等行为不变
