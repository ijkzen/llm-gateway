# 02: 接入每小时系统恢复任务

**What to build:** 将连续失败供应商自动恢复流程接入现有系统定时任务生命周期，使任务在启动时幂等种入、以每个整点为执行节拍、注册并加载处理器，且同一进程内不会重叠执行整轮恢复。

**Blocked by:** 01: 执行一轮连续失败供应商自动恢复

**Status:** completed

- [x] 新系统任务使用稳定名称、系统分组和 `@hourly` 表达式，标题与描述沿用现有任务本地化机制。
- [x] 启动时幂等种入任务，多次初始化不产生重复行。
- [x] 处理器在调度器加载任务前注册，并调用票据 01 的一轮恢复入口。
- [x] 同一进程中上一轮未结束时跳过重叠执行并记录日志。
- [x] 调度接线测试验证种子幂等、表达式为 `@hourly`、注册处理器后任务可被加载，无需等待真实整点。
