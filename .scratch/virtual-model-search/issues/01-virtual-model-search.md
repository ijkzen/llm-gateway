# 01: 虚拟模型页搜索

**What to build:** 管理员可在虚拟模型页标题栏动作区按供应商模型 ID（成员 `providerModelId`）搜索已加载的虚拟模型成员。结果按所属虚拟模型分组展示在搜索框下方浮层：组标题为虚拟模型 ID（`displayId`），组内仅列命中成员（`providerModelId` + 供应商名），停用虚拟模型及其停用/随供应商禁用成员仍出现在结果中且行内无状态标记。点击命中行打开该成员既有详情弹窗（传入所属虚拟模型与命中成员）；弹窗打开/关闭均保留搜索关键词与结果；点击结果面板以外页面区域收起面板；关键词无命中时展示无结果提示。纯前端改动，不新增后端端点或依赖，交互照搬供应商模型页搜索模式（不抽取通用组件）。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 标题栏动作区出现搜索框；输入对已加载虚拟模型成员的 `providerModelId` 做不区分大小写包含匹配。
- [ ] 命中结果按所属虚拟模型分组浮层展示（组标题 `displayId`，组内仅命中成员行），停用虚拟模型与停用/随供应商禁用成员的命中可见。
- [ ] 点击命中行打开既有成员详情弹窗并传入正确成员与其所属虚拟模型；弹窗打开/关闭后搜索关键词与结果面板保留。
- [ ] 点击结果面板以外的页面区域收起面板；关键词无命中时展示无结果文案。
- [ ] i18n 新增虚拟模型搜索专属词条（zh-CN/en 同步对齐）；既有文案如刷新按钮不变。
- [ ] 页面交互测试（既有虚拟模型页测试文件扩展）覆盖：按成员 `providerModelId` 搜索、跨虚拟模型分组、停用实体可见、点结果开详情且搜索保留、点外收起、无结果文案；`pnpm lint` 与 `pnpm vitest run` 全绿。
