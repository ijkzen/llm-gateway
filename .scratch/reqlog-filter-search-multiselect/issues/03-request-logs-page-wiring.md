# 03: 请求日志页接入多选过滤（级联 + 重置 + 查询联动）

**What to build:** 管理员在请求日志页对虚拟模型/供应商/上游模型/API Key 四项做多选过滤，日志表格即时按所选值刷新；多选供应商时上游模型选项为所选供应商模型并集（供应商为「全部」时为全部模型），供应商变化后自动剔除失效已选模型；重置按钮把所有过滤项恢复「全部」；状态过滤保留单选不变；勾选即时查询。
