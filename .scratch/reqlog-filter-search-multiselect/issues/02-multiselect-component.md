# 02: 通用 MultiSelect 多选下拉组件（搜索 + 全选 + 勾满归一化）

**What to build:** 管理员在多选下拉中可用顶部搜索框按关键词（大小写不敏感子串）过滤选项、逐个勾选/取消复选框选项、用全选三态复选框行一键全选/清空；手动勾满全部选项时组件对外表现为「全部」（等价于未选择，不产生过滤参数）；触发器显示「全部」或已选摘要。基于 Popover 弹层（引入 @radix-ui/react-popover）。文案补 zh-CN 与 en。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 搜索框输入关键词后仅显示匹配选项，清空恢复全部
- [x] 勾选/取消选项即时回调最新选中集合
- [x] 全选行三态：全选中=勾、部分=半选、无=空；点击全选=勾满、再点=清空
- [x] 手动勾满所有选项时对外值为「全部」（归一化为空集合）
- [x] 触发器摘要：未选显示「全部」，有选择显示已选名称/数量摘要
- [x] 组件单测覆盖上述行为；`pnpm vitest run` 与 `pnpm lint` 全绿
