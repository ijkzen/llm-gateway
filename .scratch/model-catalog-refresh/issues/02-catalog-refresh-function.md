# 02: 目录刷新函数

**What to build:** 一个可测试的刷新函数：GET 给定 URL 抓取 models.dev 目录数据，用与读取侧同一套结构校验为合法且非空的 JSON，通过后写同目录临时文件再原子 `rename` 覆盖目标外置文件；任何失败（网络错误 / 非 2xx / JSON 非法 / 空对象）都返回错误且**不触碰已存在的旧文件**。源 URL 与目标路径均为参数（测试传本地 mock URL + 临时文件），不新增环境变量。

**Blocked by:** 01（复用其校验入口与路径推导）。

**Status:** ready-for-agent

- [ ] 抓取函数签名接受 `(url, path)`，成功返回写入的目录条目数。
- [ ] 校验复用读取侧同一 serde 结构解析（结构不兼容即失败），并拒绝空对象。
- [ ] 写入走临时文件 + `rename` 原子替换；必要时先创建父目录。
- [ ] 非 2xx、非法 JSON、空对象、网络错误均返回错误，且已有目标文件内容保持不变。
- [ ] 不新增环境变量；源 URL 在生产 handler 处用常量传入。
- [ ] 测试用本地 mock HTTP 覆盖成功 / 非法 JSON / 非 2xx / 空对象四例，断言写入内容与旧文件保留。

**Acceptance criteria 验证方式:** `cargo test`（catalog_refresh 测试全绿，不触真实网络）。
