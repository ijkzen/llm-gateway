# 前端数据面板与表单模块收敛 — Spec

> 设计共识来自 2026-09-06 架构评审 grilling，完整决策记录见 `docs/adr/0004-frontend-panel-form-convergence.md`。
> 领域术语见 `CONTEXT.md`（数据面板、供应商模型、虚拟模型等）。

## Problem Statement

数据面板概念（时间窗口 → 查询 → 图表/赛马）由五个 overview 页面手写复刻：每页各自实现窗口 map、副标题、粒度推导与载入/错误/重试块（副标题闭包四页逐字节相同）；四张赛马卡各自复制六指标列定义、排序翻转与深链 URL 拼接；八个数据 hook 各自复制查询参数拼装、query key 与 keepPreviousData，窗口参数存在三种类型写法。每页测试要 mock 七八个 hook。表单侧，供应商模型的字段知识（校验 schema、能力开关、proxy 校验规则）在三个弹窗各写两遍且校验与字段分居两处。纯格式化函数偷读 i18n 全局单例，en 分支不可测。对用户当前没有可见问题——这是纯架构债，代价在每一次后续改动上。

## Solution

按自底向上顺序把散装知识收进四个模块：数据层一个查询模块（统一窗口类型 + 参数/key/缓存行为收拢，typed facade 原名保留）、组件层一套可排序指标表与赛马卡壳、页面层一个窗口统计区块（五页退化为配置）、表单侧一个表单知识模块（schema/能力开关/proxy 规则三块）。纯格式化函数改为显式传入语言。对管理员而言所有页面行为、默认窗口、深链跳转均与升级前一致。

## User Stories

1. As a 开发者, I want 新增一个面板过滤维度只改一处, so that 不再手改六个 hook 文件
2. As a 开发者, I want 新增一个面板数据 hook 只写五行 typed facade, so that 查询拼装/key/缓存行为自动继承
3. As a 开发者, I want 排序翻转与深链 URL 拼接有一份实现加一层直测, so that 排序行为改动不再要逐卡回归
4. As a 开发者, I want 五个 overview 页面退化为区块配置表, so that 新增一个统计区块是声明式的一行而不是复制一段骨架
5. As a 开发者, I want 窗口语义（边界、粒度、副标题）改在一处, so that 五页四卡同时生效不会漏
6. As a 开发者, I want 页面测试不再 mock 七八个 hook, so that 测试维护成本与页面数量脱钩
7. As a 开发者, I want en 格式化分支成为一等单测, so that 国际化词条改动不会静默破坏格式化输出
8. As a 开发者, I want 供应商模型校验规则与它校验的字段同址, so that 改字段时不会忘改另一处副本
9. As a 开发者, I want 能力开关网格与 schema 只写一遍, so that 新增能力开关改一处
10. As a 管理员, I want 面板与弹窗的交互、默认窗口、深链跳转与升级前完全一致, so that 重构对我不可见
11. As a 管理员, I want 时间窗口切换时保留上一窗口数据、错误时可重试的体验不变, so that 使用习惯不被打断
12. As a 开发者, I want 分步实施每步独立提交可验证, so that 任何一步出问题可单独回退

## Implementation Decisions

- 实施顺序（自底向上，每步独立提交）：可排序指标表与排序 hook（无依赖，先单测）→ 数据层查询模块 → 赛马卡壳 → 窗口统计区块收拢五页。
- 数据层：新增共享窗口/过滤类型（替换现有三种参数写法）；参数序列化、query key 构建、keepPreviousData 收进一个内部查询模块；对外保留八个 typed facade 且原名不变，调用方零改动。
- 组件层：排序逻辑（默认降序/切换翻转）抽为 hook；六指标列定义与格式化收敛为一份（与现有指标汇总卡的指标定义合并）；赛马卡壳收拢窗口控件、懒加载、载入/错误/无数据分支与重试。
- 页面层：窗口统计区块以「过滤维度 + 区块类型 + 窗口状态」为 interface，收拢粒度推导、副标题本地化与状态分支；三个默认窗口工厂语义保持现状不变（只收拢代码不改行为）。
- 表单：只收三块知识——校验 schema（上下文长度/最大输出 + 校验文案）、四个能力开关网格、proxy 校验规则（与 proxy 配置字段组件同址导出）；各弹窗的打开/重置/toast 骨架不动。
- locale：纯格式化函数加显式 locale 形参，组件在边缘经现有翻译 hook 传入；范围仅纯格式化函数，API 客户端的错误文案不动。
- 决策依据：ADR-0004（含被否决备选：单页试点先行、连弹窗骨架一起抽、formatter 工厂注入）。

## Testing Decisions

- 好测试只断言外部行为：渲染结果、点击表头后的排序与深链、窗口切换后的查询参数、错误态的重试调用——不断言内部实现细节。
- 四条 seam（均经确认）：数据层缝（参数序列化/key builder 纯函数直测 + 经 facade 验证查询行为）、可排序指标表缝（渲染点表头断言排序翻转与深链）、统计区块缝（窗口切换→参数、错误→重试，验证一次替代五页各测）、表单与 locale 纯函数缝（schema/payload 映射与格式化输出直测，不渲染弹窗）。
- 先例：图表组件测试（渲染断言）、窗口周期纯函数测试、面板页测试（区块独立性与窗口交互）、供应商模型弹窗测试（瘦身后留存部分）。

## Out of Scope

- 后端 stats 查询层收敛（架构评审候选 6，未纳入本轮；本 spec 的数据层缝为将来对缝预留）。
- 弹窗打开/重置/toast 骨架的统一（被否决，弹窗间差异大）。
- API 客户端错误文案的 locale 化。
- 任何面板新功能、新指标或页面视觉调整。
