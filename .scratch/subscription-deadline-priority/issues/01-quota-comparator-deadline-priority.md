# 01: 订阅制比较器重写为「截止日期优先」

**What to build:** 订阅组内排序从「剩余百分比主导」改为「截止日期主导」：从 5h 层起逐层检查，双方该层都有额度（窗口可用且剩余>0）→ 跳过剩余百分比，比较更上层（日→周→月）的截止时间链（早者优先、缺截止时间者排后、都缺则继续往上层）；截止链全平 → 剩余百分比兜底（沿用现有逐层逻辑）；某方该层不可用/无额度 → 判平进下一层；无数据排最后。公开函数签名与所有调用方不变（运行时 LB 与前端展示自动同步）。模块内单测重写覆盖全部新分支。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] `cmp_quota_remaining` 按新算法重写：逐层额度检查 → 截止时间链 → 剩余百分比兜底
- [ ] 单测覆盖：5h 都有额度时周截止近者优先（即使 5h 剩余更低）；周截止相同比月截止；截止链全平走兜底；某方窗口不可用判平进下一层；缺截止时间排在可判定者之后；多窗口最差剩余口径保持；无数据排最后
