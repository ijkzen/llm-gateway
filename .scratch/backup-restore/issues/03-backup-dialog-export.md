# 03: 前端备份入口与导出

**What to build:** 设置页修改密码按钮左侧新增备份入口按钮；点击打开备份弹窗（含「导出备份」「恢复备份」两个按钮）。「导出备份」调后端导出接口并把响应存为 JSON 文件下载。「恢复备份」关闭本弹窗、切换打开导入弹窗（占位由 04 提供，本票先留打开导入弹窗的接线点）。文案走 i18n。
