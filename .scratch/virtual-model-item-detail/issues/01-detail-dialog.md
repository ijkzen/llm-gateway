# 01: 成员只读详情弹窗（含启停开关）

**What to build:** 从用户视角，虚拟模型成员卡片被点击后应能弹出一个只读的「成员模型详情」弹窗——展示该成员指向的供应商模型的模型 ID、所属供应商、上下文长度、最大输出、四项能力与状态标记（「随供应商禁用」「已停用」）；弹窗内底部有一个「在虚拟模型中启用」开关，拨动即把该成员在虚拟模型中的启用位翻转并立即持久化，成功后提示、失败保持原状并报错。弹窗不允许编辑：没有编辑/删除/测试按钮。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新建 `VirtualModelItemDetailDialog`，以 `open`/`onOpenChange`/`virtualModel`/`item` 为输入，只读展示区样式对齐供应商模型详情弹窗只读态（标题=模型 ID，描述=所属供应商，`dl` 展示上下文长度/最大输出/能力项，数字 `toLocaleString()` 全量）。
- [ ] 展示状态标记：`item.enable === false` 显示「已停用」；`item.providerEnable === false` 显示「随供应商禁用」。
- [ ] 弹窗内「在虚拟模型中启用」开关：供应商停用时仍可操作；pending 时禁用；拨动调用更新接口提交翻转后的完整成员集合；成功 toast、失败 toast 并保持原状态。
- [ ] 组件测试（红→绿）：渲染只读信息与状态标记、断言无编辑/删除/测试按钮；拨动开关断言提交载荷含目标成员 `enable` 翻转且其余成员不变；供应商停用时开关仍可交互。
- [ ] zh-CN/en 词条补齐（开关标签、弹窗标题等），`en.ts` 与 `zh-CN.ts` key 对齐。
