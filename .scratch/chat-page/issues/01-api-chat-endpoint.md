# 01: `/api/chat/completions` 会话鉴权直连端点

**What to build:** 管理后台登录用户可携会话 Cookie 调用新的聊天转发端点：请求给出供应商 ID 与模型 ID 及多轮消息，后端校验目标为启用的供应商下启用模型，直连该上游并复用现有转发管线（协议转换、连接池、指标落库），以 SSE 流式回传 OpenAI chunk 风格增量（正文走 `delta.content`，思考走 `delta.reasoning_content`，结束帧带 `finish_reason`）。不走虚拟模型路由，不做 failover 重试。聊天请求照常写入 request 表。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 未登录（无会话 Cookie）调用返回 401
- [x] 不存在的供应商或模型返回 404（中文错误消息，走统一响应结构）
- [x] 停用的供应商或停用的模型拒绝对话（400，中文停用词汇）
- [x] 流式响应输出 content 与 reasoning_content 增量帧、结束帧 finish_reason
- [x] 请求完成后 request 表新增一行（指标口径与 /v1 一致）
- [x] 集成测试（build_authed_app + 本地 mock 上游）全绿，既有测试不回归

# 02: 聊天页骨架与对话闭环

**What to build:** 侧边栏「数据面板」之下出现「聊天」导航项，进入 `/chat` 页面：上方为聊天记录滚动区（用户消息靠右、助手回复靠左的气泡），下方为输入框；选定模型后发送消息，助手回复流式逐字出现，思考过程在输出期间持续展示、正文到达或流结束后自动折叠为可点击展开的摘要条；发送中可点「停止」中断并保留已收内容；可清空对话；失败在气泡内展示错误。页面纳入既有登录守卫，文案走 i18n。

**Blocked by:** 01（端点就绪）。

**Status:** ready-for-agent

- [ ] 侧边栏新增「聊天」项且位于数据面板之下，未登录访问跳登录
- [ ] 发送消息后用户气泡靠右、助手气泡靠左，回复流式渲染（纯文本保留换行）
- [ ] 思考过程流式展示→自动折叠→可手动展开回看
- [ ] 发送中「停止」可中断，已收内容保留并标注停止
- [ ] 「清空」重置对话；请求失败在气泡内展示错误信息
- [ ] 前端组件测试（mock hooks 与 fetch 流）全绿

# 03: 供应商分组模型选择浮窗

**What to build:** 输入框区域右上角可点开模型选择浮窗：因输入框贴近页面底部，浮窗**向上弹出**；内部按供应商分组（供应商名为组标题），仅列启用供应商下的启用模型；选中某供应商的某模型后发起对话，选中态在触发器上可见。复用既有 providers/provider-models 数据查询，不新增后端接口。

**Blocked by:** 02（聊天页存在后叠加）。

**Status:** ready-for-agent

- [ ] 浮窗自输入框右上角向上弹出，不被视口截断
- [ ] 模型按供应商分组展示，组内仅启用模型
- [ ] 选择后触发器展示当前选中模型（含供应商），对话请求携带对应 providerId/modelId
- [ ] 组件测试覆盖分组渲染与仅启用项
