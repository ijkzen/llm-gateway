# 02: 纯核心 — 指标注册表与闭桶/窗口分解

**What to build:** 单一事实源的指标注册表：逐个与 12 个端点现有 SQL 对账后的 metric_type 清单（计数/和原语 + 分位标量 + 哨兵），每个指标绑定「success/全量」口径谓词与整数/浮点分类——保证生成谓词与实时 SQL 同构。闭桶判定（桶终点 + 60 分钟 ≤ now）与四级日历桶（设置表时区对齐）枚举、任意窗口 [S,E) →「整闭桶集合 + 兑底段」的分解算法（边缘桶逐级降粒度到小时，最终实时尾部）。全部纯函数直测。

**Blocked by:** None（可立即开工）

**Status:** completed (2026-09-09 实现并验证)

- [ ] 注册表覆盖 summary/charts/insight/rank/metrics 所需全部原语（与各端点 SQL 口径一致，含 tps/cache 的成对和）
- [ ] 闭桶判定、桶枚举、窗口分解纯函数单测（跨月/跨年/时区偏移/任意窗口含 rank 无粒度场景）
