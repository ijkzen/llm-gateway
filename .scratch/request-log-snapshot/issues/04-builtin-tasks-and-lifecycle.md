# 04: 内置任务与生命周期（生成/自愈/回填/时区重算）

**What to build:** 两个内置定时任务（cron_jobs 种子行、init 注册 handler、zh/en 文案、JobLogLayer 日志）：
- `stats_snapshot`（@every 1h）：固化自上次以来全部新闭口桶（四级各自判定，宕机后一次补多个）；首启表空时整体全量回填整个 request 历史（按闭桶事务分片、幂等、无断点状态机）。
- `stats_snapshot_rebuild`（@every 1h）：自愈——最近 7 天缺哨兵行的闭口小时/天桶 + 最近闭月/闭年点检，缺失即补算（复用生成路径）。
- meta 记录生成时区；启动/运行时发现设置表时区变更 → 自动触发全量重算。
任务失败只记录日志不影响转发。cron 集成测试（种子幂等、被调度、手动执行、自愈补缺、时区变更触发）。
