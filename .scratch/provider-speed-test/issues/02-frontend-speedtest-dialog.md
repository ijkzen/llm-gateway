# 02: 供应商详情模型测速弹窗

**What to build:** 供应商详情左下角「更多」菜单在「删除」上方新增「模型测速」项；点击弹出对话框，列出当前供应商名下的全部供应商模型（ProviderModel）。每行左侧为模型名、右侧为「测试」按钮；点击测试调用既有测试接口（数据层 hook 已由 ticket 01 扩展为返回耗时），成功在该行显示耗时（ms）；失败以弹窗展示后端返回的错误信息。弹窗状态（耗时/错误/加载）随开关复位。

**Blocked by:** 01 后端测速接口返回请求耗时

**Status:** ready-for-agent

- [ ] 「更多」菜单项「模型测速」位于「删除」上方，点击打开弹窗
- [ ] 弹窗列出该供应商名下全部模型（过滤掉其他供应商的模型），每行左侧模型名、右侧「测试」按钮
- [ ] 点「测试」成功 → 该行显示后端返回的耗时；失败 → 弹窗展示错误信息，可关闭
- [ ] 测速中按钮呈加载态并防重复点击
- [ ] 无模型供应商显示空态提示
- [ ] 停用（enable=false）供应商的模型仍可测速（按钮不因停用禁用）
- [ ] 弹窗关闭重开后状态复位
- [ ] 前端组件行为测试覆盖上述关键路径
