# 01: 日志条目改两行布局

**What to build:** 定时任务「执行日志」弹窗里，每条日志不再把「时间 / 级别 / 内容」挤在一行，而是渲染为两行：第一行是「时间 + 级别」（级别保留 INFO/WARN/ERROR 的颜色），第二行是日志内容。实时日志与历史日志用同一个日志行组件，两处同时生效。长内容因此拿到整行宽度，扫读更容易。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 每条日志渲染为两行：第一行「时间 + 级别」，第二行「内容」
- [x] 级别（INFO/WARN/ERROR）与时间同一行，且保留原有的颜色区分
- [x] 内容行占满可用宽度，长内容正常换行、长串不溢出（保留原有 `whitespace-pre-wrap break-all` 行为）
- [x] 实时日志与历史日志两处都呈现两行布局（同一组件，不新增分支组件）
- [x] 保留原有的 memo 优化与 `log.seq` 作为列表键，不改日志数据结构
- [x] 实时模式的既有行为不回归（快照回放、按 seq 去重、实时追加、自动跟随、「回到最新」）
- [x] 前端门禁全绿：`pnpm lint`（biome，tab / 双引号 / 100 列）与 `pnpm vitest run`
