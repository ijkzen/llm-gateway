# 02: 添加供应商模型弹窗分栏

**What to build:** 管理员在添加供应商模型时可在自动添加和手动添加之间切换。对话框在内容较长时保持标题和操作区固定，仅中间内容滚动；手动添加的模型目录候选在选择或点击候选区域外时收起。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 添加对话框提供自动添加与手动添加两个 Tab，并保留两种既有业务流程。
- [ ] 对话框使用适配视口的固定高度，标题和底部操作区固定，中间区域独立滚动。
- [ ] 手动目录候选在点选候选或点击候选外部后收起，不清空当前表单输入。
- [ ] 弹窗交互测试覆盖 Tab、结构化滚动布局和候选收起行为。
