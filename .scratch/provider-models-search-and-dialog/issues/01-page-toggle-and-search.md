# 01: 供应商模型页开关与搜索

**What to build:** 管理员可在供应商模型页面的每个供应商区块直接启用或禁用供应商，并在标题栏右侧按供应商模型 ID 搜索。搜索结果按供应商分组，包含禁用供应商；点击结果打开模型详情且保持搜索会话，点击结果区域外收起结果。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 每个供应商区块的「添加」左侧有即时更新、失败回滚的启用开关。
- [ ] 页面标题栏右侧可按供应商模型 ID 搜索，并按供应商分组显示所有命中结果（包括禁用供应商）。
- [ ] 点击搜索结果复用模型详情；打开/关闭详情不清空搜索；点击结果区域外收起结果面板。
- [ ] 页面交互测试覆盖搜索、分组、详情保持、点外收起和开关失败回滚。
