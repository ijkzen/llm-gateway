# 02: 成员协议匹配与级联移除

**What to build:** 受限类型虚拟模型只能挂本协议成员：OpenAI Compatible(0)←生效协议 0、Responses(1)←生效协议 1、Messages(2)←生效协议 2、Full Compatible(4) 不限（Gemini 协议成员只能进 Full Compatible）。生效协议 = 模型级协议覆盖优先，否则供应商协议。供应商模型协议（模型级覆盖或供应商级协议）中途变更后，自动把它从不再匹配的受限类型虚拟模型中硬删成员行（成员回到未分配状态可重新添加）；Full Compatible 虚拟模型不移除。管理员修改虚拟模型接口类型时，保存自动硬删不再匹配的成员。

**Blocked by:** 01（接口类型字段与类型路由）。

**Status:** ready-for-agent

- [ ] 虚拟模型创建/更新时后端校验受限类型全部成员生效协议匹配，不匹配拒绝（不信任前端）
- [ ] 修改接口类型时在更新事务内自动硬删不再匹配的成员行
- [ ] 供应商模型协议变更（模型编辑路径）触发级联移除
- [ ] 供应商协议变更（供应商编辑路径）触发其名下模型级联移除
- [ ] Full Compatible 虚拟模型在上述变更中不移除成员
- [ ] 集成测试：两条变更路径的级联移除、Full Compatible 豁免、类型修改级联移除、受限类型添加校验（缝 B）
