# 0026 — 供应商模型共享归属：解除虚拟模型互斥映射

## Status

accepted（取代 ADR-0020 决策 2「互斥映射」）

## Context

ADR-0020 曾把「一个供应商模型最多归属一个虚拟模型」固化为域不变量（`uq_virtual_model_items_model_id` 唯一索引兜底，API 校验 + 备份导入校验 + 前端候选过滤三层配套）。实际使用中互斥限制了复用：同一供应商模型无法同时作为多个虚拟模型的成员。备选「最多两个」需要新增计数校验，无收益，选择彻底解除。

## Decision

1. 彻底移除互斥：迁移 28 将 `uq_virtual_model_items_model_id` 唯一索引换为普通索引（`model_id` 查询路径保留索引），删除管理路由「已被其他虚拟模型使用」校验、备份导入的跨虚拟模型重复校验，以及前端 `mappedModelIds` 候选过滤。
2. 同一虚拟模型内同一供应商模型仍只允许出现一次（组内去重保留）。
3. 「删除虚拟模型即释放其成员」不再成立：删除只删其名下条目，供应商模型在其他虚拟模型的归属不受影响。
